The McQueen Effect

A closer look at Lewis Hamilton’s career—and the extraordinary baseline behind the decline narrative.

View live project ↗GitHub / source ↗
01 / The question

Has Hamilton declined—or has the baseline distorted the story?

Winning became so routine during the Mercedes years that later results could look like a simple decline. This project asks what changes when that impression is checked against career outcome rates, teammates and constructor context.

02 / My contribution

From a career question to a reproducible argument.

Defined the comparison, assembled season-level data, documented sources and head-to-head conventions, wrote the Python analysis, and built the interactive HTML/CSS/Chart.js story. The finished scope is career results from 2007–2026 YTD—not telemetry or a mechanical diagnosis.

A fairer unit of comparison.

Season lengths vary. Rates per Grand Prix start make seasons comparable without letting a longer calendar inflate the result. The 2014–2020 Mercedes championship run provides an explicit peak baseline: 73 wins from 137 starts (53.3%).

Put the machinery back in the picture.

Raw trophies cannot isolate a driver. Constructor position adds team context; qualifying, race head-to-heads and teammate-pair points share add another comparison. Neither is a perfect control for reliability, setup, strategy or adaptation.

03 / Reading the evidence

The simple decline story does not hold up.

The project finds a clear drop from the peak, with weaker recent teammate comparisons—especially qualifying in 2024–2025. Its 2026 YTD snapshot also shows a rebound against Leclerc. These are descriptive comparisons, not proof that one factor caused the change.

04 / The experience

Let the reader follow the argument.

Start with the peak

Large baseline figures make the unusually high reference point visible.

Move from career to context

The sequence narrows from outcome rates to constructors, then teammates, before giving the conclusion.

Keep charts explorable

Hover values and selectable Chart.js legends let readers inspect the lines; photography and short chapters break up the analysis.

05 / Scope & sources

An argument with its limits attached.

The repository documents race-duel rules, sprint-inclusive championship points and an incomplete 2026 season. The Python script and CSVs make the baseline calculation reproducible. The final story deliberately excludes unsupported telemetry and performance-degradation claims.
