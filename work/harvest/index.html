Apple Harvest Festival

A warm, responsive event guide that connects the festival atmosphere with the details of a visit.

View live project ↗GitHub / source ↗
01 / Site goal

Make the festival feel inviting without making the practical information hard to find.

The site balances two jobs: show the atmosphere of the Apple Harvest Festival and help someone plan a visit. I treated navigation, page hierarchy and responsive behavior as part of the design—not cleanup after the visuals.

HomeActivitiesLineupGalleryInformationDirections

Give each visitor question a clear destination.

Instead of making one long page carry everything, the site separates event discovery, schedule, gallery, practical information and directions. The lineup can be scanned for time-based information while the photography keeps the page from reading like a spreadsheet.

02 / Before code

I sketched the wide and narrow layouts separately.

The sketches establish the hierarchy before implementation: navigation, a large event introduction, supporting content and a footer. The narrow version is not a squeezed desktop page; it anticipates the stack and the order content should take on a smaller screen.

03 / From sketch to browser

The finished site kept the warm festival identity but tightened how it behaves.

Visual system

Warm colour, serif display type and large photography.

The visual language is intentionally different from the data-heavy projects in this portfolio.

Responsive navigation

The menu exposes its state and supports keyboard dismissal.

The expanded navigation can be closed with Escape instead of trapping the user in a mobile overlay.

Small interactions

Tips use a native dialog and return focus to the trigger.

The interaction is simple, but it behaves like a real interface rather than a decorative modal.

04 / My contribution

Page design, responsive layout and front-end implementation.

I created the layouts and built the HTML, CSS and JavaScript across the multi-page guide. The finished project is useful here because it shows a different part of my range: visual web design, information structure and responsive implementation rather than analysis or product research.

Finished scope

Six visitor-facing sections, one responsive system.
